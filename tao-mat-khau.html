🔐 Tự đặt mật khẩu

Nhập mật khẩu mới. Trang này sẽ tạo file admin-config.js để bạn chép vào thư mục goc.

Nên dùng ít nhất 10 ký tự, có chữ hoa, chữ thường, số và ký tự đặc biệt.
Sau khi tải:
1. Mở thư mục Downloads.
2. Sao chép file admin-config.js.
3. Dán vào thư mục goc.
4. Chọn thay thế file cũ.
5. Mở lại admin-login.html.
